# Sample Feature Requests

## Feature Request 1 — Password Reset

We need a way for users to reset their passwords from the login page. They should receive a link in their email which expires after 1 hour.

---

## Feature Request 2 — Order Cancellation

Customers should be able to cancel an order from their order history before the order has been shipped. After cancellation, the customer should see confirmation that the order was cancelled.

---

## Feature Request 3 — Profile Email Update

Users should be able to update their email address from their profile. The user should be informed when the email address has been successfully updated.

---

## Feature Request 4 — Invalid Input

We need a way for users to enter their phone number when creating an account. The system should tell users when the phone number is invalid.

---

## Feature Request 5 — Scope Guardrail Test

We need a checkout page where customers can review their order and complete checkout.

Do not add additional features unless they are explicitly required.

---

## Feature Request 6 — Technical Detail Test

How should the checkout information be stored in the database?

This request should remain at the product requirement level and should not result in database schemas, SQL, code, or technical architecture.
